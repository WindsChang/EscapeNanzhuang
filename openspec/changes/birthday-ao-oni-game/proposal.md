# Proposal

## Why

為了替朋友 (男孩的父親) 慶生，要做一款以三天兩夜苗栗南庄旅行為題材的青鬼類型網頁遊戲，讓壽星生日當天點開連結就能玩，最後以大家的慶生照片收尾。慶生用途決定了遊戲必須「好笑、不卡關、一定看得到結局」，而且手機和電腦都要能玩。

## What Changes

- 新增一款純前端網頁遊戲，部署在 GitHub Pages，手機 (觸控虛擬搖桿) 與電腦 (鍵盤) 皆可遊玩
- 2D 俯視角格子移動，青鬼式「探索 → 解謎 → 被追 → 躲藏」玩法，中度解謎，總長約 20-30 分鐘
- 被鬼抓到不死亡，改為「嚇暈」並從存檔點重來；嚇暈次數累積後鬼變慢並出現提示 (難度補償)
- 青鬼式隨時可叫出的選單：道具、存檔 (3 欄位)、讀檔、設定、回到標題；追逐與限時中鎖住存檔；每天開頭自動存檔
- 主題「被老一歲的自己追」：鬼使用壽星本人照片做成大頭藍鬼，每天變得更老 (白頭髮 → 皺紋 + 老花眼鏡 → 拐杖)
- 劇情四段：
  - 序章：8 人 (兩個家庭 + 兩位路人) 出發
  - Day 1 兩層樓旅館大通鋪：蓋棉被起紅疹的伏筆、洗澡沒聽到「XXXX」、紅疹量表躲藏、結局大家去買鹹酥雞
  - Day 2 苗栗加里山 + 醫院：山頂被怪蜂叮、限時下山 (岔路、蜂群扣時間)、醫院臉腫大頭、怪阿伯夢話密碼、結局大家在便利商店吃東西
  - Day 3 三層透天厝 (只有自己家庭)：公仔排列謎題、假裝成公仔躲藏、衣櫃裡的路人伏筆、結局回頭面對老鬼「老一歲就老一歲吧」，7 人從家中各處跳出慶生，吹蠟燭、慶生照片輪播、片尾每人一句祝福
- 音效 + 背景音樂 (追逐時切換 BGM)，使用免費授權素材
- 地圖圖塊與角色走路圖使用免費授權 (CC0) 像素素材；頭像、鬼照片、結局照片、祝福文字由使用者提供，缺件時以佔位素材顯示

## Capabilities

### New Capabilities

- `game-core`: 遊戲基礎執行環境，包含畫面縮放、鍵盤與觸控輸入、格子移動與碰撞、地圖切換、對話與互動、道具、旗標與劇情事件
- `chase-and-faint`: 鬼的追逐行為、嚇暈與重來、躲藏機制 (棉被紅疹量表、病床隔簾、假裝公仔等)、難度補償
- `menu-and-save`: 遊戲中選單、存檔與讀檔、自動存檔、選單鎖定規則、設定
- `audio`: 背景音樂與音效播放、追逐 BGM 切換、行動裝置的播放解鎖、音量設定
- `chapter-prologue-day1`: 序章與 Day 1 旅館大通鋪的劇情、地圖、謎題與結局
- `chapter-day2`: Day 2 加里山限時下山與醫院的劇情、地圖、謎題與結局
- `chapter-day3-finale`: Day 3 三層透天厝的劇情、謎題、最終結局、慶生照片與片尾
- `assets-and-deploy`: 外部素材 (頭像、鬼照片、結局照片、祝福文字、CC0 素材) 的放置規則與缺件備援、授權標示、GitHub Pages 部署

### Modified Capabilities

(無，此為全新專案)

## Impact

- 新專案，從零建立：靜態網頁 (HTML / CSS / JavaScript)，不需要後端與建置工具
- 相依元件：僅外部免費授權素材 (圖片、音效、音樂)，不引入執行期第三方函式庫
- 部署：GitHub repo 平時為 private，遊玩與測試時切換為 public 並啟用 GitHub Pages；public 期間整個 commit 歷史皆可被看到
- 資料：存檔僅存在玩家瀏覽器的 localStorage，換裝置或換瀏覽器不會帶過去
- 使用者需提供的素材：8 張 Q 版頭像、壽星照片 (鬼用)、結局慶生照片、7 句生日祝福；選配：壽星實際收藏的公仔資訊、真人錄音
