# Spec Delta

## Purpose

定義使用者提供的個人素材與免費授權素材如何放入遊戲、缺件時如何備援、授權如何標示，以及遊戲如何部署到 GitHub Pages 供遊玩與測試。

## ADDED Requirements

### Requirement: 使用者素材放置規則
遊戲 SHALL 從固定資料夾與固定檔名讀取使用者提供的素材：8 位角色的 Q 版頭像、壽星照片 (老鬼用)、慶生照片 (多張)、7 句祝福文字與角色名稱；替換素材 MUST 只需替換檔案或編輯一份文字設定檔，不需要修改程式。

#### Scenario: 替換頭像
- **WHEN** 使用者把新的頭像圖片以約定檔名放進頭像資料夾
- **THEN** 重新整理頁面後對話框顯示新頭像

#### Scenario: 修改祝福文字
- **WHEN** 使用者編輯祝福設定檔中某人的祝福句
- **THEN** 片尾顯示更新後的祝福句

### Requirement: 缺件備援
任何使用者素材缺件時，遊戲 SHALL 以佔位素材 (佔位頭像、佔位老鬼、文字畫面) 呈現，MUST 能從頭玩到片尾不中斷。

#### Scenario: 全部缺件
- **WHEN** 尚未提供任何使用者素材
- **THEN** 遊戲可從序章完整玩到片尾

### Requirement: 老鬼由壽星照片產生
老鬼外觀 SHALL 由一張壽星正面照片產生：以照片作為大頭並套上藍色調，再依章節疊加老化道具 (白頭髮、皺紋、老花眼鏡、拐杖)；使用者只需提供一張已去背或背景單純的正面照片。

#### Scenario: 提供照片
- **WHEN** 使用者以約定檔名放入壽星照片
- **THEN** 三天的老鬼都使用這張照片並各自顯示對應的老化道具

### Requirement: 免費授權素材與標示
地圖圖塊、角色走路圖、音效與音樂 SHALL 只使用允許免費使用的授權素材 (以 CC0 為優先)，專案 MUST 附上一份素材來源與授權清單，需要標註作者的素材也在片尾的素材致謝中列出。

#### Scenario: 檢查授權
- **WHEN** 檢視專案的素材授權清單
- **THEN** 每個第三方素材都列出來源網址與授權類型

### Requirement: 純靜態部署
遊戲 SHALL 為純靜態檔案，可直接由 GitHub Pages 提供服務，MUST 不需要建置步驟、後端服務或外部 CDN 才能執行，所有路徑使用相對路徑以支援 `https://<帳號>.github.io/<repo>/` 的子路徑。

#### Scenario: GitHub Pages 子路徑
- **WHEN** 遊戲部署在 `https://<帳號>.github.io/<repo>/`
- **THEN** 所有圖片、音效與程式都能正確載入

#### Scenario: 本機測試
- **WHEN** 開發者以任意本機靜態伺服器開啟專案根目錄
- **THEN** 遊戲可正常遊玩

### Requirement: 部署與私有切換說明
專案 SHALL 附上部署說明文件，包含：將 repo 切換為 public 並啟用 GitHub Pages 的步驟、遊玩結束後切回 private 的步驟、切回 public 時需確認 Pages 設定，以及 public 期間整個 commit 歷史皆可被看到的提醒。

#### Scenario: 依文件部署
- **WHEN** 使用者依部署說明操作
- **THEN** 可取得可分享的遊戲網址，並在之後將 repo 恢復為 private

### Requirement: 載入畫面
遊戲 SHALL 在素材載入期間顯示載入進度，載入完成後才進入可點擊的標題畫面。

#### Scenario: 慢速網路
- **WHEN** 玩家以較慢的手機網路開啟遊戲
- **THEN** 顯示載入進度，載入完成後出現標題畫面
